# AI Architecture - CIEL (Conversational Intelligent Economic Layer)

## Overview
CIEL acts as the user's personal Chief Financial Officer. It runs on a multi-tier tool execution pattern:

1. **Context Synthesizer**: Compiles recent transactions, accounts, health score, and goals into a token-efficient system prompt.
2. **Tool Execution Engine**: Equipped with deterministic tools to query accounts, simulate outcomes, and calculate projections.
3. **Safety & Guardrail Layer**: Validates AI outputs to prevent risky financial suggestions.
