# Database Architecture - Financial OS

## Core Entities
- **Users**: User authentication and profile settings.
- **Accounts**: Depository, credit, investment, and loan accounts.
- **Transactions**: Double-entry compatible transaction ledger with category tags.
- **Bills & Debts**: Recurring obligations, interest rates, minimum payments.
- **Goals**: Target amounts, dates, and automatic contribution rules.
- **Health Snapshots**: Historic financial score metrics.
- **AI Conversations**: Chat sessions and tool invocation logs.
