# User Personas - Financial OS

## Persona 1: The Active Builder (Alex, 29)
- Tech professional managing multiple income streams, investments, and savings goals.
- Needs: Real-time net worth tracking, scenario simulation, automated debt paydown guidance.

## Persona 2: The Busy Household Planner (Jordan, 38)
- Managing family budget, mortgage, kids' education funds, recurring subscriptions.
- Needs: Predictable safe-to-spend numbers, automated recurring bill alerts, anomaly detection.
