# User Flows - Financial OS

## 1. Authentication & Onboarding Flow
1. User registers or logs in via OAuth/Email.
2. User connects primary bank accounts or imports CSV statements.
3. System runs initial financial health audit and displays baseline score.

## 2. Safe-to-Spend Calculation Flow
1. Ingests current account balances, upcoming bills for the cycle, and goal allocations.
2. Calculates variable discretionary spend pool.
3. Updates dashboard in real-time.
